# 0.5.1 release notes

This patch fixes large Query, Fetch, and List results failing with
`Unexpected document payload shape from URL` in 0.5.0.

- Accept the JSON document arrays returned by signed `docsUrl` downloads across
  ordinary and Safe methods, GET/POST List, and document pagination.
- Preserve support for `{ docs: [...] }` payloads, request options, existing
  error handling, and downloads without forwarded API credentials.
- Add regression tests and a required live release smoke test that exercises
  actual large-result downloads and verifies temporary Collection cleanup.

No application code changes are required when upgrading from 0.5.0.

The download format is pinned to [server revision
`d1a76659884a9ed09283a0b2e2989897dc799247`](https://github.com/lambdadb/lambdadb/blob/d1a76659884a9ed09283a0b2e2989897dc799247/runtime-aws/src/main/java/ai/lambdadb/service/queryexecutor/QueryCoordinatorService.java#L280-L301).
The public OpenAPI contract remains
[`c44180406c05b1a9043d8516e7c7f60df91fc9a7`](https://github.com/lambdadb/docs/blob/c44180406c05b1a9043d8516e7c7f60df91fc9a7/reference/api/openapi.json).

```bash
npm install @functional-systems/lambdadb@0.5.1
```
